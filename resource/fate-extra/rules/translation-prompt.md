# Fate/Extra 中文翻译规则

以下规则仅在项目启用 `fate_extra.adapter.v1` 时追加到翻译提示。

1. 只翻译正文，不输出 `路径 | char:数字 |` 索引，也不要添加解释、注释或 Markdown。
2. 原文与译文的物理行数、空行位置、行顺序及逐行对应必须严格一致。禁止新增、删除或移动换行；同一逻辑文本的多行容量不得拆成逐行容量。
3. 原样保留并保持顺序：`{end}`、`#Cxxxxxx`、`#CDEF`、`#RUB`、`#RUBE`、`#ROFS`、`#REND`、`#SIZE(x)`、`<ICON>`、`\n` 及其他 `#` 控制符。
4. 从者、性别和其他条件分支必须完整翻译，不得只保留当前可见分支。
5. 日文原文优先于既有英文；含义冲突或专有名词不确定时采用保守译法并留待人工校对。
6. UI、战斗文本和对白应简洁、自然，不作无必要扩写；不设置统一的画面尺寸阈值。
7. 不得用空格替代控制符，不得合并或拆分 Ruby 结构，不得擅自改变变量、图标、颜色、字号和偏移参数。
8. 每条逻辑文本会附带独立 JSON 容量约束。`slot_capacity` 是游戏编码后的字节容量，不是字符数、UTF-8 长度或像素宽度；计数包含物理换行与原样写入的控制符文本，不包含 NUL 终止符和槽位填充。
9. `slot_capacity=null` 时只需保持简洁；`allow_overlength=true` 时允许超过原槽位；否则译文游戏编码字节数不得超过 `slot_capacity`。
10. 重试约束中的 `previous_translation`、`previous_encoded_bytes` 和 `must_reduce_bytes` 表示上一版超限结果。重写时至少缩短指定游戏编码字节数，同时保持含义、口吻、控制符和物理换行结构。
11. 分类、容量、地址和权限字段只供翻译判断，不得在译文或 JSONLINE 输出中复述。
